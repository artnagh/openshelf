## Install a skill

```bash
# into this project
npx degit <owner>/<repo>/<path-to-skill> .claude/skills/<name>
# for every project
npx degit <owner>/<repo>/<path-to-skill> ~/.claude/skills/<name>
```
Every component page on the site gives you the exact command. **Read a skill before you install it.**
